# Sachman Overseas

Website mockup for **Sachman Overseas** — an IELTS, PTE, Spoken English, and study-visa consultancy based in Pathankot, Punjab.

## What's included

- Multi-page site: Home, Services, Countries, Process, and Contact
- Sideways study-country carousel
- Contact / free consultation form (client-side mock)
- Responsive layout for mobile and desktop

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Stack

Next.js · TypeScript · Tailwind CSS · shadcn/ui
